01 — Replay

Same failure. Twice.

Pick one of ten real Sui failures. Session 1 is the first time the agent meets it. Session 2 is a fresh chat, a different day — and the answer is already waiting in Walrus. Everything here was recorded from real simulations and real mainnet writes.

02 — The gate

Nothing is remembered until the chain agrees.

Other agent memories store what the model says worked. Déjà Fix's remember_fix accepts exactly one thing: a verification ID from a passing simulation the server ran itself.

03 — Where memory matters

Memory earns its keep where the error stops explaining.

A good model fixes textbook errors from the message alone, and our own test shows it. Memory matters when the message says what failed but not what your project needs. Each case below is labeled by how much evidence we have.

How to read the labels: Measured is in our results (small sample). Demonstrated means we ran it end to end once. Expected is our reasoning, not yet tested.
